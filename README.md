## What this project does
Housing affordability is a major urban challenge. Predict apartment prices from area, location, size and amenities, after cleaning inconsistent square-feet entries and removing outliers, and map affordable localities.

## Dataset
Kaggle — Bengaluru House Price Data
https://www.kaggle.com/datasets/amitabhajoy/bengaluru-house-price-data

## How to run
Open the notebook in Google Colab and run all cells.

## Best Results
- Regression: **MLP (64-32)** — RMSE = 45.72 lakh, MAE = 21.63 lakh, R² = 0.744 (22% lower RMSE than the median ₹/sq-ft baseline of 58.60)
- Classification (selected by cross-validated F1): **SVM (RBF)** — F1 = 0.691, AUC = 0.928 (CV-F1 = 0.698)
- Best test-set classifier: **MLP (64-32)** — F1 = 0.701, AUC = 0.934
